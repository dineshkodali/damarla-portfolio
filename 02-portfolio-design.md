# Design Specification

## Humanised Professional Portfolio

### 1. Design Direction

Create a calm, modern, professional portfolio that feels like a real
person's website.

The design should be: - Clean - Warm - Practical - Confident but not
arrogant - Professional without feeling corporate - Easy to scan -
Suitable for the UK recruitment market

Avoid a futuristic AI aesthetic.

### 2. Visual Style

Use: - A light background - Dark navy or charcoal text - One restrained
accent colour - Soft grey borders - Moderate rounded corners - Plenty of
whitespace - Simple line icons - Real project screenshots where
available

Avoid: - Neon gradients - Excessive glassmorphism - Heavy shadows -
Animated backgrounds - Too many cards - Stock-photo-heavy layouts -
Oversized decorative typography - Fake metrics or visual noise

### 3. Typography

Use a readable sans-serif font such as: - Inter - Manrope - DM Sans -
System UI

Suggested hierarchy: - H1: 42--56px desktop, 34--40px mobile - H2:
28--36px - H3: 20--24px - Body: 16--18px - Small text: 13--14px

Prioritise readability over visual effects.

### 4. Layout

Use a maximum content width of approximately 1100--1200px.

Desktop: - Header with name/logo on the left - Navigation on the right -
Main content in a single clear column - Two-column layouts only when
useful

Mobile: - Simple menu - Stacked sections - Comfortable spacing - Large
touch targets - No horizontal scrolling

### 5. Homepage Structure

#### Header

-   Personal name or simple wordmark
-   About
-   Experience
-   Projects
-   Contact
-   Optional CV link

#### Hero Section

Include: - Natural professional headline - Two- or three-line
introduction - Primary button: View Projects - Secondary button:
Download CV - Optional small location label: United Kingdom

Example: "Business Analytics and HR professional interested in turning
business challenges into clear, practical insights."

Do not use exaggerated statements such as "world-class expert" or
"revolutionary problem solver."

#### Career Focus

Show three simple areas: 1. Business Analytics 2. HR Management 3.
Business Consultancy

Each area should have a short explanation.

#### Featured Projects

Show 2--3 projects only on the homepage. Each project card should
include: - Title - Short description - Project category - Tools - View
case study link

#### Experience Preview

Show a short timeline or concise experience list. Link to the full
Experience page.

#### Closing Section

Use a friendly, professional invitation: "Open to connecting with people
working in analytics, HR, consulting, and business improvement."

### 6. Project Page Design

Each case study should use a consistent structure:

1.  Project overview
2.  Business problem
3.  Objective
4.  Approach
5.  Tools used
6.  Key findings
7.  Recommendations
8.  Outcome or learning
9.  Reflection
10. Related projects

Use charts, screenshots, process diagrams, or tables only when they help
explain the work.

### 7. Components

Build reusable components: - Header - Footer - Button - Section
heading - Project card - Skill group - Experience timeline item - Case
study section - Tag or category label - Contact form - CV download link

Keep components simple and easy to maintain.

### 8. Accessibility

-   Use semantic HTML.
-   Add alt text to meaningful images.
-   Do not rely on colour alone.
-   Maintain readable contrast.
-   Make focus states visible.
-   Ensure keyboard navigation.
-   Label all form fields.
-   Use descriptive link text.

### 9. Interaction

Use restrained interactions: - Subtle hover states - Simple link
transitions - Small fade or slide effects only if needed - No
auto-playing media - No distracting scroll animations

The website should remain useful even if animations are disabled.

### 10. Content Tone

Tone should be: - Human - Clear - Professional - Thoughtful - Direct

Write like a capable early-career professional, not like an AI marketing
agency.

Avoid phrases such as: - "Leveraging synergies" - "Transformative
thought leader" - "Disruptive innovation" - "Unparalleled expertise"

Prefer: - "I analysed..." - "I supported..." - "I developed..." - "I
identified..." - "I recommended..." - "I learned..."
